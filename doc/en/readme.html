Discord Messages Reader

Discord Messages Reader is an NVDA add-on for Discord stable, PTB, and Canary. It checks Discord's UI Automation tree every 500 milliseconds and presents new messages through speech and braille.

Requirements

  • NVDA 2026.1 or later (tested with NVDA 2026.2)
  • A Windows version supported by NVDA 2026.1
  • Discord stable, PTB, or Canary

Using the add-on

Open a Discord channel or direct message. The add-on announces new messages only while Discord is the active window. It establishes a silent baseline after startup, channel changes, foreground return, and unmute, so existing messages are not announced as new.

Keyboard commands

  • NVDA+Alt+Shift+D toggles automatic announcements.
  • Alt+1 reads the most recent message.
  • Alt+2 through Alt+9 read the second through ninth most recent messages.
  • Alt+0 reads the tenth most recent message.

You can change these commands in NVDA's Input Gestures dialog under Discord Messages Reader.

Limitations and privacy

The add-on can read only messages currently exposed in Discord's accessibility tree. Discord updates can change that tree and temporarily affect detection.

  • A burst of more than 10 new messages is announced as the first 10 followed by the number of messages left out. Each message is cut to 500 characters. Alt+1 through Alt+0 review them.
  • A message whose Discord timestamp is more than a minute old is never announced, so history you scroll to, open from a link, or that Discord loads after a reconnect stays silent.
  • Your own messages are announced once, when you send them.
  • Nothing is announced while NVDA is in sleep mode for Discord. In NVDA's on-demand speech mode, automatic announcements appear in braille only; Alt+1 through Alt+0 and the toggle still speak.

Speech can disclose private messages to nearby people. Use NVDA+Alt+Shift+D when you do not want automatic announcements. Before sharing an NVDA log in a bug report, remove Discord message text, usernames, channel names, tokens, local paths, email addresses, and other private data.
